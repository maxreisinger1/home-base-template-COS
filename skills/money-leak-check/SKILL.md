# Money leak check

Goal: find money {{OWNER_NAME}} is losing without deciding to, and make stopping it a 2-minute job. Use any spending goal saved in project memory.

## Sources
- Personal Gmail (a second Gmail connection, if set up): receipts, "your subscription renews", "price is changing", trial-ending, refund and late-fee emails over the last 60-90 days.
- Any statement or transaction data {{OWNER_NAME}} has shared in project files. Only use bank or card tools {{OWNER_NAME}} has connected for personal accounts; Ask before reading any business bank account.

## Find
1. Recurring charges: name, amount, cadence, last charge, and whether there's any sign {{OWNER_NAME}} uses it.
2. Price increases and promo rates ending.
3. Free trials about to convert.
4. Refunds promised but not received; return windows still open.
5. Fees and interest: late fees, foreign fees, card interest. Put the APR cost in dollars per month.
6. Duplicates (two music, two cloud storage, etc.).

## Output
One short table, sorted by dollars per year saved, with a recommendation per row: cancel, downgrade, ask for retention offer, or keep. Total possible savings at the top. Be honest, not preachy: keep things {{OWNER_NAME}} clearly values.

## Acting
- Never cancel, buy, call or email a company without {{OWNER_NAME}}'s yes on that specific item.
- For each yes, give the fastest path: a direct cancel link, an online chat, or a 3-line script (prefer no-phone options). Offer to do it in their browser if possible.
- Add each chosen action to Home Base tasks.

## After
Log findings and decisions in memory file money-leaks.md (what {{OWNER_NAME}} kept and why, so we don't re-suggest it).
