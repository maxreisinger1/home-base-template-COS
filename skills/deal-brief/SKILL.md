# Deal brief

Never answer a deal question from memory alone.

## Steps
1. Check project memory for the deal note.
2. Search Drive, Gmail (all mail), Notion meeting notes and Calendar for the deal name and contacts.
3. If a document is an attachment the Gmail connector cannot open, say so up front and ask for a Drive copy or pasted text once. Never guess its contents.
4. Update or create the deal note: documents with links, key numbers, dates, who owes what, open questions.
5. Output a brief: where it stands, what the other side wants, what {{OWNER_NAME}} owes, what the numbers say against {{NORTH_STAR_SHORT}}, risks (legal, margin, capacity), recommended next move with owner and date.

## Rules
- Cite every claim (thread, doc, event) and say how sure you are. Never invent numbers; write "ask {{OWNER_NAME}}".
- NDA deals stay in {{OWNER_NAME}}'s own channels, never anything shareable.
- Draft replies only. Never send.
- Hot notes for this week's deals; archive older ones and pull on mention.
- Ask "does this need to be you?" if the next step could be owned by someone else.
