# Weekly kickoff pages

Every Monday {{OWNER_NAME}} needs fresh Notion pages for the weekly kickoff meetings (for example an exec kickoff and a project leads kickoff). A scheduled task makes them early Monday so nobody has to ask.

## Set this up once
Fill in for each meeting: the page title pattern (e.g. "Exec Weekly Kickoff | M/D/YY"), the Notion parent database, the properties to set, and the section template (agenda, each person's top 3 priorities with a brain dump box, carryover, notes).

## Steps
1. Date = today in the owner's time zone.
2. Search Notion for today's titles first. If a page exists, don't duplicate; give the link.
3. Build from the saved TEMPLATE, not from last week's filled page (people delete sections while filling it in).
4. Create FRESH pages. Never duplicate last week's (its notes and priorities would copy over).
5. Carryover = unchecked action items from last week's notes plus still-open carryover. One line each, owner first. Never invent items; skip ones clearly done.
6. Before finishing, fetch each page and check every person has their block.

## Rules
- Don't share the pages, change permissions, post in Slack or notify attendees without a yes.
- Deliver the links in one line. Say plainly if anything failed.
