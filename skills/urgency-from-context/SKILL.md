# Urgency from context

## Steps
1. For each incoming ask, list what it touches: a person, a doc, a deal, a decision.
2. Check what's coming up in the next 72 hours: the calendar, open threads, recent meeting transcripts, and Home Base tasks.
3. If the ask feeds into something on that list, it inherits that event's deadline. Flag it with the link spelled out: "Sam's title is on the org chart you present tomorrow at 11."
4. If nothing connects, rank it normally. Topic alone (title, pay, etc.) doesn't make something urgent.
5. Suggest the natural moment to handle it, like an existing meeting before the deadline.

## Rules
- Lead with the deadline and why, in one line.
- Don't invent urgency. If there's no link, say so.
